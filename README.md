- **Dual Slab Specimen Showcase:** Side-by-side high-resolution photographs of Block #23 Front View (फ्रंट व्यू) and Back View (बैक व्यू).

## 💻 Local Development

Run the built-in HTTP server:
```bash
# Ruby WEBrick server
ruby -rwebrick -e 's = WEBrick::HTTPServer.new(:Port => 8000, :DocumentRoot => Dir.pwd); trap("INT"){ s.shutdown }; s.start'

# Or Python 3
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
